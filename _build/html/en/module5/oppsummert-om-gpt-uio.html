Summary of GPT UiO

Use GPT UiO if you

  • need a safe and good chat service
  • want to use a GPT UiO AI assistant that a colleague has shared with you, or try one of UiO’s selected AI assistants
  • need to handle red data (choose a model that supports red data)
  • want to be sure that none of your data is sent to the cloud (choose a local model)
  • want to easily switch between larger models (OpenAI’s GPT models) that run in the cloud or one of the smaller open models that run on UiO’s or NTNU’s IT systems
