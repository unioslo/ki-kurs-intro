Practical exercise: Improve prompts

Now try improving the prompts from the previous page in GPT UiO yourself. This will give you a good indication of how the language model responds to the prompts you give.

Try it yourself!

Open GPT UiO and try to improve the prompts in the examples from the previous page yourself.

1. Improve poor prompts

Copy each of the inadequate prompts below into GPT UiO, and look at the answer you get:

  1. “Explain the difference between AI and machine learning.”
  2. “Create meeting minutes from these notes: [your notes]”
  3. “Check this text: [your text]”
  4. “Write a title for a news story about us getting a new system for travel expense claims.”

2. Write improved versions

Then rewrite each prompt so that you use all the principles from the previous page

  • Give context
  • Specify format
  • Define a role
  • Give examples

Test the new prompts in GPT UiO and compare the answers with the ones you got in point 1.

3. Reflection

Consider the following:

  1. What became better in the answers after you improved the prompts?
  2. Which of the principles (context, format, role, examples) had the biggest impact on quality?
  3. How can you use these principles in your own, actual work tasks (for example emails, case documents, website texts)?
