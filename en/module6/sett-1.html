Set 1

Exercise 1: Prompts

Explore 2 different AI services and practise different techniques for writing prompts. Feel free to discuss with a colleague how the various services work and what they are suited for.

Exercise 2 - Idea generation

Ask an AI tool to generate 10 ideas for how AI can be used in your everyday work. Clearly specify what kinds of tasks you do and which tools you have available.

Exercise 3 - Gemini Notebook

Upload a document to Gemini Notebook. Choose a document that is relevant to your job, or a document you are interested in. Create a mind map and a study guide, and ask questions about the content of the document.

Exercise 4 - Creating templates

Think of an area of your work where you often create similar documents or texts. Use one of the available AI tools to create a draft template you can use in your work.

Exercise 5 - AI assistant

Set up your very own AI assistant in GPT UiO.

  1. Choose one task you do often (e.g. responding to enquiries, creating agendas, summarising meetings).
  2. Create a “standard prompt” that you can reuse, describing: - Your role and field of work - A typical target audience - The desired style and format
  3. Test the prompt on an example from your job.
  4. Refine the prompt until you have a version you can use as a template going forward.

Exercise 6 - Image generation

You are going to send out an invitation to a meeting on a topic of your choice. Ask Copilot to generate a relevant image you can use in the meeting invitation.

Exercise 7 - PowerPoint

Ask Copilot to create a draft of a PowerPoint presentation on a topic of your choice.

Exercise 8 - Simple programming

We want Excel to sum the numbers in two columns automatically.

To achieve this, we have written a short macro:

Sub LeggTilTall()
   Dim sisteRad As Long
   Dim i As Long

   sisteRad = Cells(Rows.Count, 1).End(xlUp).Row

   For i = 2 To sisteRad ' Antar at første rad er header

   Cells(i, 3).Value = Cells(i, 1).Value + Cells(i, 1).Value
Next i
End Sub

Unfortunately, this code snippet contains an error, and the sums we get do not match our expectations.

  • Task 1: Get GPT to explain what is wrong with the code snippet, and why it does not give the sum of columns A and B.
  • Task 2: Get GPT to write a correct version of the code that actually gives the sum of columns A and B.

The exercise can be solved using only the code snippet above and GPT UiO, but for those who happen to be extra curious, there is an Excel file with the described functionality available here if you want to test it yourself: Enkel-koding-med-KI.xlsx
